# Clínica Fisio Palmas Altas — demo

Demo navegable de una plataforma integral para una clínica de fisioterapia y entrenamiento funcional. Está diseñada para mostrar una experiencia personalizada y el valor diferencial de AI4G frente a un software de gestión estándar.

## Qué incluye

- Panel de dirección con facturación, ocupación, margen y rentabilidad por servicio.
- Agenda combinada con calendarios diferenciados y filtros para fisioterapia, suelo pélvico, Pilates, funcional y embarazo.
- Gestión de pacientes e historia clínica con plantillas por especialidad.
- Bonos, cuotas, pagos y control de impagos.
- CRM comercial con origen de contactos y embudo de conversión.
- Automatizaciones de listas de espera, renovaciones y reactivación.
- Asistente AI4G con recomendaciones basadas en los datos ficticios de la demo.
- Acceso desde la ficha clínica al portal móvil del paciente, con selección de clase, validación de bono y confirmación de reserva.

## Ejecutar en local

No requiere instalación ni compilación. Abre `index.html` en un navegador o sirve la carpeta con cualquier servidor estático.

```bash
python -m http.server 8080
```

Después visita `http://localhost:8080`.

## Alcance y privacidad

Esta es una demo visual y funcional. Todos los nombres, importes e historiales son ficticios. No almacena datos, no procesa pagos y no debe utilizarse como sistema clínico real. La seguridad, RGPD/LOPDGDD, historia clínica, facturación y VeriFactu requieren diseño, validación jurídica y pruebas específicas antes de una implantación.

## Tecnología

HTML, CSS y JavaScript sin dependencias de producción.
